| אשרי יושבי ביתך | מאושר היושב בביהמ"ד |
| עוד יהללוך סלה | ועוד שגם מהלל |
| אשרי העם שככה לו | כך מובטח שכרו |
| אשרי העם שה' אלוקיו | מלכו ומתכבד בו |
| תְּהִלָּה לְדָוִד אֲרוֹמִמְךָ אֱלוֹהַי הַמֶּלֶךְ | אותו לא נשיג רק נרממו |
| וַאֲבָרֲכָה שִׁמְךָ לְעוֹלָם וָעֶד: | אחרי שרוממתי אברך |
| | ברכה המשכת השפע |
| בְּכָל יוֹם אֲבָרֲכֶךָּ | גם שרע לי אברך |
| וַאֲהַלְלָה שִׁמְךָ לְעוֹלָם וָעֶד | ע"י שאברך אזכה לעתיד לבוא להלל |
| } גָּדוֹל יְהוָה וּמְהֻלָּל מְאֹד | בחסדיו הכי ניכר גדולתו |
| וְלִגְדֻלָּתוֹ אֵין חֵקֶר | לעולם לא נכיר היכף גדולתו |
| דּוֹר לְדוֹר יְשַׁבַּח מַעֲשֶׂיךָ | כל דור מכירים יותר פלאי הבריאה |
| וּגְבוּרֹתֶיךָ יַגִּידוּ | ניסים מספרים מדור לדור |
| הֲדַר כְּבוֹד הוֹדֶךָ | את היופי החיצוני נוכל לספר |
| וְדִבְרֵי נִפְלְאוֹתֶיךָ אָשִׂיחָה | השיחה שלי היא בנפלאותיך |
| וֶעֱזוּז נוֹרְאֹתֶיךָ יֹאמֵרוּ | העם יספרו פחד ה' |
| וּגְדוּלָּתְךָ אֲסַפְּרֶנָּה | ואני אספר רוב גדולת ה' בבריאה |
| זֵכֶר רַב טוּבְךָ יַבִּיעוּ | גם הם יתחילו לספר טובך |
| | ורק קצת אפשר להספיק |
| וְצִדְקָתְךָ יְרַנֵּנוּ | וכמה צדק יש בכל פעולה. |
