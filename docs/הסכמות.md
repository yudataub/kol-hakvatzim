# הסכמות הרבנים.

### הסכמת הרב אביגדור נבנצל שליט"א.

יקר סהדותא

ראיתי את החוברת "שלום בית" המסבירה איך אהבה ואחוה ושלום ורעות בין איש לאשתו גורמים שפע טוב של הקב''ה לכנס''י, והדברים מאירים ומעוררים, יזכה הרב המחבר שליט"א לעורר כל בית ישראל בזה, ונזכה שהקב''ה, למרות שצדוקי א' בגמ' (סנהדרין לט.) אמר עליו שהוא כהן, יחזיר את גרושתו במהרה בימינו.

### הסכמת הרב דב יפה שליט"א, משגיח דישיבת כנסת חזקיהו רכסים.

ההסכמה החשובה של הגאון הרב נבנצל שליט"א אינה צריכה חיזוק ויזכה הרב המחבר הנכבד לעורר רבים לטובה.

### הסכמת הרב יואל שוורץ שליט"א.

מכתב ברכה

הנה ידידי הרב החשוב יהודה טאוב שליט"א

הביא לפני את כתביו בנושא שלום בית והפליא ללקט את דברי רבותינו הקדושים בענין חשוב זה המקשר את הקב''ה וכנס''י, במעשה החסד ואהבה שבין איש לאשתו, על כן ראוי לכל איש מישראל ללמוד את המקורות שבלקט היקר הזה, ויוסיף להוסיף לקח, ללמד את חובת כל אדם מישראל.
