בס"ד

**מבחן מס' 1 - ז' אייר תשע"ה**

מבחן בגמ' נידה דף ב. - ג: (איתמר קופה)

### הוראות למבחן:

על פי החלטת הנהלת הכולל:

1. המבחן יערך בין השעות 4-5 אחה"צ.
2. יש לשבת במקומות נפרדים בזמן המבחן.
3. יש לשמור על השקט בשעת המבחן.
4. את התשובות יש למסור לראש הכולל.
5. המילגה על המבחן בעז"ה 50 ₪.
6. יש לענות על ז' שאלות.

### שאלות.

1. אשה הרואה דם ממתי טמאה? (ג' דעות)
2. מתי כולם מודם שדיה שעתה? ולגבי מה כולם מודים שדיה שעתה? (מופיע במשנה)
3. מה הדין במקרים הבאים לגבי מה שהיה למפרע:

| | | | | | |
| --- | --- | --- | --- | --- | --- |
| | אשה שראתה דם | מקוה שנמדד ונמצא חסר | חבית שנמצאה חומץ | שרץ שנמצא במבוי | סוטה |
| טמא ודאי | - | | | | |
| טמא ספק | לבית הלל | | | | |
| טהור | לבית שמאי | | | | |

1. מדוע שמאי סובר שאשה לא מטמאה למפרע? (ד' טעמים)
2. מדוע כתמים טמאים הרי אשה מרגישה שיוצא דם לשמאי?
3. אשה ששמשה במוך וראתה דם ממתי היא טמאה? (חשבן לפי כל השיטות)
4. אשה שנגעה באביה ובבעלה ובתוך כ"ד שעות ראתה דם האם הם טמאים לפי הלל?
5. אשה שראתה דם ללא הרגשה כגון שבדקה בעד וראתה דם, לפי שמאי ממתי היא טמאה? ומה הטעם לא חישינן כשם שעכשיו לא הרגישה כך אתמול לא הרגישה?

בהצלחה.

### מבחן מס' 2.

גמ' נידה דף ג: (איתמר) - ה: (כיצד דיה שעתה)

1. פרט שלוש סוגי קופות? (דף ג:) (עם שולים בלי וכ"ו)
2. מה דין כל אחת מהם - בנמצא שרץ? (דף ג:)
3. כתוב שלוש (מתוך ארבע) אוקימתות למחלוקת ר"י וחזקיה.
4. אין מחזיקים טומאה ממקום למקום - האם זה בתורת ודאי או בתורת ספק?
5. מתי לא אומרים ספק טומאה ברה"י להחמיר?
6. אשה שיש לה וסת האם אומרים דיה שעתה לפי ר' דוסא ולפי חכמים? (לפי ב' הלישנאות)
7. אשה שלא בדקה שחרית, וערבית בדקה ומצאה דם - ממתי היא טמאה לפי חכמים ומדוע? (רשות: ומה הדין עם באונס לא בדקה בשחרית)
8. האם כתם מטמא למפרע או מעת לעת? (פרט בכל סוגי הנשים)
9. נאמר במשנה "והמשמשת בעדים הרי זו כפקידה" כתוב שני הסברים למשפט זה!
10. קופה עם שולים, קופה ללא שולים וללא אוגנים, קופה ללא שולים עם אוגנים.
11. קופה עם שולים - טמא לכו"ע, קופה ללא שולים - טהור לכו"ע, קופה עם שולים ויש לה אוגנים - נחלקו חזקיה מטהר, ור' יוחנן מטמא, (ובמים לכו"ע טמא).
12. (ארבע תירוצים): א. ב"ש וב"ה דיברו בקופה שיש לה שולים, חזקיה ור"י דיברו בקופה שאין לה שולים ויש לה אוגנים. ב. ב"ש וב"ה דיברו בקופה שאינה בדוקה, חזקיה ור"י מדברים בקופה בדוקה. ג. ב"ש וב"ה מדברים בקופה שאינה מכוסה, ור"י וחזקיה נחלקו בקופה מכוסה ד. ב''ש וב''ה נחלקו בקופה במקום שנמצא בה הדם, ור''י וחזקיה נחלקו בקופה במקום אחר.
13. לפי חזקיה בתורת ודאי, לפי ר' יוחנן בתורת ספק.
14. בדבר שלא ניתן להישאל, בטומאה דרבנן.
15. לפי לישנא קמא: בשעת וסתה לכו''ע דיה שעתה, שלא בשעת וסתה נחלקו ר' דוסא וחכמים, לפי לישנא בתרא: בשעת וסתה נחלקו ר' דוסא וחכמים, שלא בשעת וסתה לכו"ע לא אומרים דיה שעתה.
16. מעת לעת, שקנסו אותה חכמים היות ולא בדקה שתפסיד עונה נוספת. גם באונס מפסידה מעת לעת.
17. אשה רגילה כתם מטמא למפרע, אשה שדיה שעתה (ארבע נשים ילדה זקנה,מעוברת ומינקת) נחלקו: ר"מ מטמא למפרע, וחכמים דיה שעתה. וקטנה שראתה כתם - טהורה.
18. פירוש א: אם שמשמה בעדים לאחר תשמיש עד לה ועד לו ממעט מפקידה שנחשב בדיקה. פירוש ב': נאמר שני דינים במשנה: א. צריכה אשה לשמש בעדים לפני תשמיש ואחריו, ב. ובדיקה שלאחר תשמיש ממעטת מפקידה למפקידה.
