# השכר האמיתי

כתב הגר"א:וכל רגע ורגע שאדם חוסם פיו זוכה בשבילו לאור הגנוז שאין מלאך ובריה יכולים לשער

וכתב הגר"א:ועד יום מותו צריך האדם להתיסר ולא בתעניתים וסיגופים רק ברסן פיו …וזהו יותר טוב מכל התעניתים והסיגופים שבעולם

## יהודים רחמנות

חברך יושב ולומד כבר שעה שלימה באמצע אתה בא ושואל אותו שאלה כעניני חולין אתה יודע מה עשית לו הרסת לו שעה של לימוד, למה מה עשה לך שככה הרסת לו שעה שלימה שהוא עמל, האם גם לאשתך היתה זורק את העוגה שאפתה לשבת לפח הזבל?

### חשוב לדעת

האיסור לדבר באמצע הענין הוא איסור גמור דהינו כאשר אתה באמצע הסעיף אסור מדינא דגמרא להפסיק לדברים אחרים אלא אם כן זה מצווה עוברת שאינה יכולה לעשות על ידי אחרים

שגמרת את הענין(כגון סימת את הסעיף את הח"מ את הב"ש)מדינא מותר לדבר אלא שיש ענין גדול ללמוד ברציפות ולא לעשות תלמודו קרעים קרעים

דע האיסור לדבר באמצע ענין הוא איסור גמור והוא מופיע במ"ב (רפה שע"צ יא) ובשו"ע (יו"ד רמו יז ובט"ז שם)

חשוב הדבר דומה למי שיכין כוץ מיץ תות בננה וישים בתוכו כפית עפר האם תשתה את הכוס? לא,

אז למה לבורא עולם אתה שולח כזאת כוס?
