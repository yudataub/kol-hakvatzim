רעיונות לרישום בפנקס ההודיה

1. עשה רשימה של חסדי יסוד שעליה תחזור תמיד.
2. לאחר מכן רשום מידי יום לפחות דבר אחד חדש שאתה מרגיש כלפיו חווית מתנה מהבורא. דברים שאתה מרגיש שבורא עולם אוהב אותך ולכן נתן לך אותם.
3. דברים שקשים לך וכדו' אין מקומם בפנקס ההודיה.
4. פרט את ההנאה שהרגשתה שהגיעה החסד, זכרו ברכת מודים היא הברכה הארוכה ביותר בשמונה עשרה, ללמדנו שגם אם בהרבה דברים ניתן לקצר, בהודיה צריכים להאריך.
5. מידי פעם כדאי להתבונן בחסדים קבועים בעולם ששם אותי הבורא, במקום בו אני נמצא.
6. פרט לעצמך את החסדים: בתור בן אדם בעולמו של הבורא, בתור יהודי (תורת חיים, משנה תנ''ך גמרא חגים וכ''ו) בתור בן לדורו של משיח, (ארץ ישראל, כוללים, שפע כלכלי, מחשב פלאפון )
