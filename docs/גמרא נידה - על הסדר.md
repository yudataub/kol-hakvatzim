בס"ד

### דף ז:

1. מדאוריתא אין אוכלין ומשקין מטמאין כלים.
2. מדרבנן כלים נטמאים ממשקים.
3. הקלו רבנן שרק אחורי הכלי יטמא.
4. כלי שאחוריו טמא ממשקין מטמא משקין (להיות ראשון) ולא אוכלין (אפילו לתרומה).
5. ר' יהושע רצה שיפסול את התרומה, ק"ו מטבול יום?
6. ענה ר"א שרק משקין שבקל מקבלים טומאה (שאין צריכים הכשר) גזרו רבנן.
