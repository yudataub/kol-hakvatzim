# סימן רנ"ב

1. אסור להנות מנר שהדליק גוי עבור הישראל בשבת אפילו בקצץ.
2. מחלוקת האם מותר להנות בשבת מחפץ שגמר גוי בשבת או במוצ"ש בכדי שיעשו אפילו כאשר נתן לו לעשות בקציצה, ובשעת הצורך ובספק מותר
3. אסור לקחת כלים מבית אומן גוי שעושה חפצים לפי הזמנה אפילו שגמר מערב שבת קודש מפני מראית עין
4. יש אוסרין גם מפני עובדין דחול וממילא אסור אפילו בחנות ואפילו של ישראל
