**סיכום מעלת ההודאה**

| | | |
| --- | --- | --- |
| | | מקורות |
| יהא שמא רבא מברך | מה הפירוש מבורך? כתב החינוך מצווה ת''ל: שכולם יברכו אותו ויודו לשמו. וכך משמע מהמשך הקדיש יתברך וישתבח ויתפאר. וגם בזה מובן מדוע הוא מעלה כל כך גדולה. | וכן נראה ממה שאמרו אשרי המלך **שמקלסין** אותו בביתו כך. |
| שבת דף קיט/ב אמר רבי יהושע בן לוי: כל העונה אמן יהא שמיה רבא מברך בכל כחו - קורעין לו גזר דינו. פירוש בכל כוחו. | שאלה: מה הפירוש בכל כוחו? מפרש רש"י בכל כוונתו. וצריך עיון איזה כוח צריך להפעיל בשביל לכוון 7 מילים פשוטות? מפרש המ''ב: סימן נו סעיף א ד''ה יש לכוין - כי אחז"ל כל העונה איש"ר מברך בכל כחו קורעין לו גזר דינו ופירשו הראשונים דר"ל בכל כחו בכל כונתו ובכל איבריו **דהיינו** שיאמרנה בלב ונפש ולא רק כמוציא שפתיו ולבו בל עמו. נראה לבאר: שאדם באמת ישתוקק בכל ליבו ונפשו שכל עם ישראל יתחילו להודות ולשיר ולאהוב את הבורא יתברך. | |
| מה המקור לזה ? | שם בגמ' שבת: שנאמר בפרע פרעות בישראל בהתנדב עם ברכו ה'. מאי טעמא בפרע פרעות - משום דברכו ה'. רש"י בפרוע פרעות - ביטול פורעניות, כגון פרוע דמתרגמין בטל. בהתנדב עם ברכו - כשמתנדבין ישראל לברך את בוראן. ולפי זה לא רק איש''ר אלא כל מקום שיש רבים שמודים. ויש לשאול: הרי באיש''ר לא מודים רק מבקשים שיודו ומנין לגמ' שזה מבטל את כל הפרעוניות? וחשבתי לתרץ שכתוב כאן יסוד גדול שהקב''ה מחשיב את הרצון של יהודי כאילו כבר נעשה וממילא כאילו יש כאן רבים שמודים ומהללים. | |
| מעלתו: שולחן ערוך (נו סעיף א) להשתדל לרוץ כדי לשמוע קדיש. משנה ברורה: עניית איש"ר הוא מצוה גדולה מאד. איש"ר עדיף טפי מקדושה ומודים. מדוע? | באיש''ר אנו אומרים לעולם ולעלמי עלמיא - אנו מבקשים שנזכה להודות ולהלל את בורא עולם, גם בעולם הזה וגם לעולם הבא, ועל כך מעלתו גדולה עד מאוד. שזה כל תכליתנו, וכמו שאמרו שלעתיד לבוא הכול בטל חוץ מקרבן תודה. | |
| מדוע ברכת כהנים לאחד מודים? מדוע לאחר ברכת המזון מבקשים כל כך הרבה בקשות? מדוע בבקשות בעשי''ת כולם קצרות אבל בשים שלום ארוכה מאוד? | תשובה: לאחר שאדם מודה לקב''ה כל שערי הברכה נפתחין לפניו. שנאמר: בואו שעריו בתודה. כיצד נכנסים לשערי הברכה על ידי תודה. רע''א: זובח תודה יכבדנני - ושם דרך אראנו בישע אלוקים. | |
| מקור בתורה שכל הברכה והשפעה למי שמודה, כל הצרות למי שלא מודה. | פרשת כי תבוא מתחילה בברכה שאין כדוגמתה ושמחת בכל הטוב (שלושה דברים: א. שמחה. ב. בכל. ג. הטוב.) ומסימת בקללות נוראות: תחת אשר לא עבדת בשמחה, בטוב לבב, מרב כל. (שלושה דברים) אם תודה בכורים - כל הברכה, לא מודה כל הצרה. | |
| מדוע תיקנו ברכת הטוב והמטיב לדורות בברכת המזון? | לחנך את עם ישראל בגלות, שצריך לחפש על מה להודות, לחפש בתוך הצרה דבר קטן טוב (שלא הסריחו) ולהודות ולהלל עליו. שהרי כל הגלות בגלל שלא הודו - ותיקונה שנחפש להודות. | |
| היכן מצאנו בהסטוריה צרות בגלל שלא מודים? | בזמן דוד המלך מתו מאה אנשים בכל יום בגלל שלא הודו לה'. | |
| מנין ידע דוד שמתים בגלל שלא מודים? | כתוב ברוח הקודש - אבל יתכן שלמד זה ממה שבפרשת הקללות יש מאה קללות בגלל שלא מודים לה' יתברך. | |
| מתי ה' נושא פנים לישראל? | פני יהושע מסכת ברכות דף כ עמוד ב. דרש רב עוירא כו' אמר להם וכי לא אשא פנים לישראל כו' והם מדקדקים עצמם עד כזית ועד כביצה. לכאורה יש לתמוה וכי לא היה להקב"ה להזכיר שום דקדוק וסייג לישראל אלא בענין ברכת המזון והלא הרבה יותר גדרו גדרים וסייגים מן העריות והרבה כיוצא באלו? אלא כאשר אדם יודע להודות גם על דברים פשוטים הוא פותח את אוצרות הטוב. | |
| מנין שמי שמודה לקב''ה נהיה שמח? | בסוף הביכורים יש ברכה ושמחת בכל הטוב. הפסוק אומר: אשרי העם יודעי תרועה - ה' באור פניך יהלכון **בשמך יגילון כל היום**. | |
| מה קורה שאדם מודה לה'? | זוהר :חובה על האיש לספר תמיד לפני הקב''ה ולפרסם כל נס פרטי מכל אותם הנסים שעשה עימו הקב''ה בפרטות ולהודות עליהם , ואם תאמר למה הוא חובה על האדם לספר נסי הקב''ה והרי הקב''ה יודע הכל? לפי שכל אותם דיבורים עולים למעלה וכל המוני מלאכי מעלה מתקבצים ורואים אותם והם מודים ומשבחים לפני הקב''ה ומתעלה כבודו עליהם למעלה ולמטה , ועוד ע''י סיפור הנסים שעשה עמו הקב''ה גורם להאיר את הספירות העליונות עתה באותם ההארות שהאירו לו בשעת הנס . | |
| למה עושים שלום זכר? | בבא קמא דף פ/א: רב ושמואל ורב אסי איקלעו לבי שבוע הבן ואמרי לה ישוע הבן. וכתבו התוס' (ד"ה ישוע הבן) בשם רבינו תם שעושין סעודה על שם שהולד נושע ונמלט ממעי אמו. **יש''ש:כדי ליתן שבח למקום**, או לפרסם המצוה, או לפרסם הנס, קרוי סעודת מצוה, כגון **לפרסם הנס**, שנמלט הזכר והאשה. | |
| מנין לסעודת הודיה? | קרבן תודה עם ארבעים לחמים. אברבנאל ויקרא פרק ז. ועם זה נשיב גם כן למה הבדיל השם שלמי תודה להיותם נאכלים ליום ולילה ושאר השלמים נאכלים לשני ימים ולילה אחד כמו שמבואר בפרשה. כי הנה היה זה כדי לפרסם הנס וזה שהבעל שלמי תודה כשהוא רואה ששלמיו אינם נאכלים אלא ליום ולילה עד חצות הוא מזמין על שלמי תודתו אחיו ואוהביו ומיודעיו לאכול ולשמוח עמו וישאלו זה את זה על מה היה תודתו והוא יגיד להם הנסים והנפלאות שעשה עמו השם וירוממוהו בקהל עם ובמושב זקנים יהללוהו. ואלו היו שלמי תודה נאכלים כשאר השלמים לשני ימים ולילה אחד לא היה הבעל מזמין לשום אדם כי לשני ימים ולילה אחד בבית אחד יאכל. אבל בראותו הבשר והלחם רב בביתו ושלא יאכל אלא ליום ולילה אחד בהכרח יקרא רבים ממיודעיו ואחוזת מרעהו לאכול פן יהיה ביום המחרת ללעג ולקלס לבני אדם הרואים אותו שורף כמות גדול מתודת שלמיו ואת אחיו ואוהביו לא קרא והותרה במה שפירשתי בזה השאלה | |
| היכן רואים בתורה שהקב''ה מחבב מאוד אדם שחי הודיה לה'? | יפה שיחתן של עבדי אבות יותר מתורתן של בנים - שכן אליעזר ידע להודות ולהלל לקב''ה על חסדיו. | |
| סיפורים על הודיה | י''ז אלול תרצ''ט - הרב הרמן יורד מהספינה משאיר את כל המשא ושמח מאוד שאחרי כל הטובות שה' נתן לו הוא יכול לתת לה'. וזה הפוך מהשואה שקראה באותו יום (סוף המאה של כי תבוא וכן מאה קללות כנגד שנת המאה) | |
| כל תפקיד האדם להודות? | עם זו יצרתי לי תהילתי יספרו. | |
