תודה לה' יתברך יוצר הכול

שוב בבוקר כמו תמיד פקחתי את עיני

ואוטומטית בלי לחשוב נטלתי את ידי

מודה אני מיד אמרתי מתוך כוונה

ותוך כדי מילאתי שוב את ספל לנטילה

מבט העפתי לחלון לראות מה שם נשמע

וריח טוב של גשם באוויר נישא

מיהרתי לי אל המטבח המים להרתיח

שכוס קפה טובה חמה אוכל פה להרוויח

ולא שמתי לב בכלל לאושר הגדול

לכול מה שקיבלתי כאן בכלל בלי לעמול

ה' נתן לי מתנות ברצף בלי לחדול

תודה ה" תודה ה" אתה כל יכול

עיניים יש לי שרואות את כל מה שסביב

גוונים יפים צבעים יפים בסתיו ובאביב

לראות פנים של ילד מותק וגם חברות

האפשרות לקרוא ברצף מלים ואותיות

לראות את האוכל הטעים שה" ברא
