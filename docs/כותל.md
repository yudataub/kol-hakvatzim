# לתושבי הרובע היהודי

באתי לבקש מעם החסד בקשה שתוכל לעזור בעז"ה להרבה יהודים טובים

כידוע יש הרבה יהודים המקפידים לקרוע את חולצתם שבאים לכותל המערבי

במיוחד יהודים שאינם תושבי ירושלים

והנה נודע לי על מקרה שאשה הגיע לרובע היהודי ונזכרה שאין בידה

חולצה לקריעה ומחמת זה נמנעה מללכת ולבקש בשריד בית מקדשינו

ולכן אבקש מיהודים המתגוררים בסמוך לכותל המערבי

להקים בביתם גמ"ח חולצות לקריעה

ניתן להשיג חולצות פשוטות בגמחי"ם יד שניה ללא תשלום
